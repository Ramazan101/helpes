# AI Self-Service Assistant (Helpes — «Кыргыз Алтын»)

Документация по модулю консультационного ИТ-помощника (`apps/assistant`), подготовленному к демонстрации руководству компании.

---

## 1. Назначение и архитектура

Модуль помогает сотрудникам компании «Кыргыз Алтын» самостоятельно проверить простые типовые неполадки (принтер, интернет/Wi-Fi, монитор, питание компьютера, зависшее ПО) на русском и кыргызском языках до вызова мастера в кабинет.

### Доступные интерфейсы:
1. **Desktop / Web (`/assistant/`)** — полноэкранный интерфейс для работы с компьютера, ноутбука, планшета или смартфона. Включает быстрые подсказки и индикатор режима работы. Ссылка на страницу вынесена в общую навигацию (`templates/base.html`).
2. **Плавающий виджет (`templates/assistant/includes/widget.html`)** — встроен на открытых страницах подачи заявки (`/`) и успешного оформления (`/success/<ticket_number>/`). Не отображается в закрытых интерфейсах техников (`/tech/`) и администраторов (`/manage/`).
3. **Серверный JSON API (`POST /assistant/api/chat/`)** — единая точка обработки сообщений с CSRF-защитой, валидацией длины, санитизацией истории и ограничением частоты запросов (`AI_ASSISTANT_RATE_LIMIT`).

## 2. Настройка переменных окружения (`.env`)

Для включения генеративных ответов через бесплатный роутер OpenRouter укажите в файле `.env`:

```ini
# Настройки AI-помощника самообслуживания (Helpes AI Assistant)
AI_ASSISTANT_ENABLED=True
AI_API_KEY=sk-or-v1-ваш_ключ_от_openrouter
AI_BASE_URL=https://openrouter.ai/api/v1
AI_MODEL=openrouter/free
AI_ASSISTANT_TIMEOUT=15
AI_ASSISTANT_MAX_MESSAGE_LENGTH=1000
AI_ASSISTANT_MAX_HISTORY=6
AI_ASSISTANT_RATE_LIMIT=15
```

### Назначение параметров:
- `AI_ASSISTANT_ENABLED` — флаг включения генеративного сервиса (`True`/`False`).
- `AI_API_KEY` — API-ключ (обрабатывается только на сервере, никогда не передаётся в браузер).
- `AI_BASE_URL` — базовый URL API провайдера (по умолчанию `https://openrouter.ai/api/v1`).
- `AI_MODEL` — идентификатор модели (по умолчанию `openrouter/free`, не требует платных OpenAI-кредитов).
- `AI_ASSISTANT_TIMEOUT` — тайм-аут ожидания ответа провайдера в секундах (по умолчанию `15.0`).
- `AI_ASSISTANT_MAX_MESSAGE_LENGTH` — максимальная длина входящего вопроса (по умолчанию `1000` символов).
- `AI_ASSISTANT_MAX_HISTORY` — глубина контекста диалога (по умолчанию `6` сообщений).
- `AI_ASSISTANT_RATE_LIMIT` — лимит запросов в минуту с одного IP/сессии (по умолчанию `15`).

## 3. Честный локальный справочный режим (без ключа)

При отсутствии `AI_API_KEY` или при `AI_ASSISTANT_ENABLED=False`:
1. Модуль **не имитирует** генеративный искусственный интеллект.
2. В интерфейсе явно отображается статус: `Режим справочной памятки (ИИ не подключён)`.
3. Запросы сверяются с локальной базой знаний (`apps/assistant/knowledge_base.py`). Если тема опознана (принтер, сеть, питание, зависшее ПО), возвращается проверенная памятка безопасных шагов самопроверки на языке пользователя (RU/KY).
4. Если готового сценария нет или произошёл сбой сети провайдера — интерфейс выводит понятное уведомление и кнопку быстрого перехода к оформлению заявки (`#publicTicketForm`).

## 4. Безопасность и защита данных

- **Изоляция секретов:** Ключ `AI_API_KEY` считывается только бэкендом Django через `django.conf.settings` и никогда не выводится в HTML/JS.
- **Политика неразглашения (Policy Guard):** Встроенный эвристический фильтр блокирует вопросы об обходе паролей, правах администратора и системных ограничениях, возвращая предупреждение и предложение вызвать специалиста.
- **Приватность корпоративных данных:** Модели передаётся исключительно вопрос пользователя и локальный контекст базы знаний. Данные базы заявок, имена пользователей, телефоны или пароли модели **не передаются**.
- **XSS-защита:** Все текстовые сообщения рендерятся в DOM исключительно через безопасный `textContent`.
- **Защита от спама и DoS:** Серверный rate limiting в Django cache ограничивает частоту запросов.
- **CSRF-валидация:** API защищён механизмом CSRF-токенов Django.
